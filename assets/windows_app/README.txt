WATERBUDDY FOR WINDOWS

1. Extract this ZIP file.
2. Double-click "Install WaterBuddy.cmd".
3. A WaterBuddy icon will appear on your Windows Desktop.
4. Double-click the icon whenever you want to open WaterBuddy.

Chrome opens WaterBuddy in a clean app-style window. If Chrome is unavailable,
the shortcut uses your default browser. The installer adds no background
processes, enables no Windows startup item, and never stores your password.

To remove the shortcut, double-click "Remove WaterBuddy.cmd".
